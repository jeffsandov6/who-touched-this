# security

if you find a security vulnerability in Who Touched This, please report it privately.

email: **[hello@whotouchedthis.website](mailto:hello@whotouchedthis.website)**

please do not:

* open a public issue or pull request containing vulnerability details
* publicly disclose an unpatched vulnerability
* test exploits, brute-force attacks, destructive behavior, or other intrusive techniques against the production website without explicit permission
* access, modify, download, or expose data that does not belong to you

when reporting an issue, include enough information to understand & reproduce the problem safely.

security fixes may be handled as platform maintenance rather than community contributions.

when a dedicated security contact becomes available, this file may be updated to use it.
